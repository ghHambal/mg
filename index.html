 BACKUP เครื่องเดียว

แผนสำรองเมื่อ Wi‑Fi ไม่พร้อม ให้ตัวแทนทีมมาพิมพ์ที่เครื่องครู
1. เปิด server ที่เครื่องครูใช้คำสั่งด้านล่าง แล้วเลือก URL ที่เป็น IP วง Wi‑Fi เพื่อส่งให้เด็ก
2. ครูเปิด Host + Scoreboardใส่รายชื่อทีมทั้งหมดใน Host แล้วกดเริ่มจับคู่ ส่วน Scoreboard ลากไปขึ้นโปรเจกเตอร์หรือจอทีวี
3. เด็กเข้าหน้าทีมคู่ที่กำลังแข่งใช้ลิงก์ทีมแดง/น้ำเงิน ทีมชนะถูกบันทึกเข้ารอบถัดไปและอันดับรวมทันที
ใช้งานหลายเครื่องจริง ให้เครื่องครูและ iPad/มือถือเด็กอยู่ Wi‑Fi เดียวกัน จากนั้นเปิด server ในโฟลเดอร์นี้: node room-server.js
แผนสำรองถ้า Wi‑Fi ไม่พร้อม เปิด `power-arena-exponent-battle.html` บนเครื่องครูเครื่องเดียว แล้วให้ตัวแทนทีมมาพิมพ์คำตอบ หรือครูพิมพ์แทนตามคำตอบของแต่ละทีม คะแนนและโจทย์ยังทำงานได้ครบ.
